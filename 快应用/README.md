### 快应用

快应用文档 https://doc.quickapp.cn/

快应用是可以秒开的安卓应用，开发上可以理解成安卓小程序， 但是在不同厂商上表现有差异，需要做适配（有点坑，这点微信小程序做的比较好）,关于不同机型的兼容适配，厂商会提供云真机测试，如果遇到审核，或者用户手机表现与测试机器不一样可以上去测试。（比如vivo开放平台的云真机调试）

快应用开发语言是一种类vue语法的语言，css样式仅支持文档所列的通用样式。

这里记录下快应用的一些坑点

#### 广告接入注意事项

1.广告接入测试时，必须使用对应系列手机，且媒体与广告位审核通过后方可获取到广告；

2.广告接入测试时，预览版调试不支持广告接口的（包括云真机）；

3.所测试/发布的快应用包名，必须与后台申请广告 ID 一一对应，否则无法成功拉起；

4.各家需要单独申请广告 ID，并且在代码中做相应适配，手机品牌，须与广告 ID 保持一致。

5.提前准备备案工作，不同平台包名一定要统一。

6.ad 组件每家都有些小差距，仔细看各家的文档，比如 oppo 需要添加 type="native" ，ad组件必须设置宽高，其他家则没要求。 同时ad组件里最好不要嵌套 两层 if 语句，会有bug。虽然24年快应用联盟开发者大会提出规划是要统一各家规范，目前暂未实现。

7.如果遇到 TypeError: The ‘compilation‘ argument must be an instance of Compilation 报错 删除 package.json "fa-toolkit": "^14.0.1-Stable.300",
